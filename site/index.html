Execution boundary

This dashboard is intentionally local-only.

It can organize a server recipe, select local files, and prepare commands in your current browser session. It cannot install Java, download a server JAR, create files, send console commands, or start Minecraft.

Those actions belong to the connected Minecraft Server Studio desktop application, where local paths, downloads, and process status can be checked safely.
